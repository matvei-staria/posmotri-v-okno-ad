# Посмотри в окно

Учебный проект Яндекс Практикума: страница для просмотра коротких видео из разных городов. Вёрстка выполнена по макету в рамках третьего спринта курса по HTML и CSS.

**Ссылка на репозиторий:** https://github.com/matvei-staria/posmotri-v-okno-ad

[Макет в Figma](https://www.figma.com/design/ApJjZAA3pBv2tCZM9E2ul2/2-%D1%81%D0%BF%D1%80%D0%B8%D0%BD%D1%82.-%D0%9F%D0%BE%D1%81%D0%BC%D0%BE%D1%82%D1%80%D0%B8-%D0%B2-%D0%BE%D0%BA%D0%BD%D0%BE?node-id=1-214)

## Возможности

- Поиск видео по названию города и времени суток.
- Переключение основного видео по нажатию на карточку.
- Подгрузка дополнительных карточек кнопкой «Показать ещё».
- Прелоадеры во время загрузки и сообщения при ошибке или отсутствии результатов.
- Кастомные чекбоксы, состояния наведения, нажатия и видимого фокуса для работы с клавиатуры.

## Технологии

HTML5, CSS3 и JavaScript. Для раскладки используется Flexbox, для состояний элементов — псевдоклассы и псевдоэлементы. Названия классов организованы по БЭМ. Шрифты Oswald и Fira Sans Condensed подключены локально через `@font-face`.

Видео и карточки загружаются с API [v-content.ffapi.ru](https://v-content.ffapi.ru). Для их получения требуется подключение к интернету.

В проекте использована учебная заготовка с готовой HTML-разметкой, JavaScript и частью стилей. Основная работа — оформление страницы по макету.

## Запуск

Сборка и установка зависимостей не нужны. Для запуска через локальный сервер потребуется Python 3.

1. Клонируйте репозиторий и перейдите в его папку:

   ```bash
   git clone https://github.com/matvei-staria/posmotri-v-okno-ad.git
   cd posmotri-v-okno-ad
   ```

2. Запустите сервер:

   ```bash
   python3 -m http.server 8000 --bind 127.0.0.1
   ```

3. Откройте [http://127.0.0.1:8000](http://127.0.0.1:8000) в браузере.

Для остановки сервера нажмите `Ctrl+C` в терминале.

## Структура проекта

```text
index.html           — разметка страницы и шаблоны карточек
styles/style.css     — основные стили проекта
styles/preloader.css — оформление индикатора загрузки
styles/error.css     — оформление сообщения об ошибке
scripts/script.js    — запросы к API, поиск и переключение видео
fonts/               — файлы шрифтов и стили их подключения
.github/workflows/   — запуск учебных автотестов через GitHub Actions
```

Макет рассчитан на окно 1200 × 800px. На больших экранах содержимое центрируется; при меньшем окне сохраняется размер сетки и появляется прокрутка страницы.
